1. Install into a clean project

Checking your local sandbox…

Do this in the terminal
./demo install

2. Run the coding task

Each run starts a fresh agent session. Only currently admitted, matching judgments are supplied.

Do this in the terminal
./demo run
./demo run --surface public

3. Give it a project judgment

This demo scopes your correction to internal knowledge URLs. Changing the text does not broaden those conditions.

Do this in the terminal
./demo capture --text 'Your correction and its reason'
./demo revise --text 'Your revised guidance'

4. Review, then try again

Inspect the exact record before approving it. A pending revision leaves the admitted version active. Withdraw wrong guidance to stop future retrieval.

Do this in the terminal
./demo review
./demo run
./demo withdraw
./demo run
