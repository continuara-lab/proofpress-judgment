# Local inspection surface

Inherit Proofpress paper/green identity. Operate mode: desktop-first, readable on mobile. Warm paper #f5f3eb, ink #183d35, muted ink #50665e, dividers #ccd5cb. One column learning sequence and a plain inspector; no dashboard cards. Serif headings (Georgia), system sans body, monospace only for commands and JSON. Native controls, visible focus, status and errors. All records untrusted text rendered through textContent. Detail stays collapsed until requested.
