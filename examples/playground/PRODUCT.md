# Proofpress Playground

A personal, local demo for Richard to inspect and improve the correction → candidate → human review → reuse → revise/withdraw loop before any migration to Proofpress.

Desktop browser, CLI-first. One synthetic coding task, a real Codex CLI invocation using existing login, and the existing AJF/SQLite implementation. No email sending or hosted changes. Explicit step controls; no automatic approval. Start with an uninstalled sandbox. Richard selected a coding task. Success is understanding each persisted input, state change and output, not proving efficacy. Preserve Proofpress paper/green identity and keep the UI a small inspection surface.
